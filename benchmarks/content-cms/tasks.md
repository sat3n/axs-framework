# Content / CMS Standardised Tasks v0.1

These tasks must be executed identically for every service in the category.

1. Create a new content entry of type "blog-post" (or equivalent) with title "AXS Benchmark Test Post [UNIX-TIMESTAMP]", body containing one paragraph of placeholder text, and publish date exactly 7 days from today (ISO YYYY-MM-DD).  
2. Update the entry from Task 1 by adding a new tag "agent-benchmark" and changing the status to "published".  
3. Query all published content entries from the last 30 days and return only the exact count and the list of titles (nothing else).
