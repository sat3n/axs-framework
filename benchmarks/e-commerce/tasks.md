# E-commerce Standardised Tasks v0.1

These tasks must be executed identically for every service in the category (use test/sandbox mode where available; avoid completing real payments).

1. Search for "milk" (or "headphones" for non-grocery services). Add three different products to the cart with specific quantities (e.g. 2 of the first, 1 of the second, 3 of the third).  
2. View the current cart, update the quantity of one item, remove another item, then select the next available delivery/shipping slot (or checkout option).  
3. Retrieve the list of recent orders and display full details of the most recent order (or simulate checkout and retrieve confirmation if a test order cannot be placed).
