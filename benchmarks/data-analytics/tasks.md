# Data & Analytics Standardised Tasks v0.1

These tasks must be executed identically for every service in the category.

1. Create a new dataset/table named "axs_test_[UNIX-TIMESTAMP]" with columns: id (integer), name (string), value (decimal), created_at (timestamp). Insert exactly 5 sample rows.  
2. Run a query that aggregates the total value grouped by a categorical field (e.g. status or category) and returns the results.  
3. Query all records created in the last 30 days and return only the exact row count and the list of names (nothing else).
