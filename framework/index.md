# Framework

The AXS framework consists of three core documents:

- [Scoring Methodology](scoring-methodology) — Full scoring rubrics, composite formula, tier classification, anti-gaming policy, version handling, and reproducibility requirements
- [Test Protocol](test-protocol) — Step-by-step guide to running a standardised AXS assessment (45–90 min per service)
- [Category Weights](category-weights) — Category-specific dimension weighting for eight service types, with rationale
